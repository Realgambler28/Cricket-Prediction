# 🏏 Cricket Prediction

A Python-based IPL match prediction project that uses Machine Learning to estimate match-winning probabilities.

## Features
- IPL match win prediction
- Interactive Streamlit dashboard
- Match data analysis
- Win probability visualization
- AI-powered cricket assistant

## Tech Stack
- Python
- Streamlit
- Pandas
- Scikit-learn
- Plotly
- Ollama (Qwen 2.5)

## Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Realgambler28/Cricket-Prediction.git
```

2. Install the required libraries:

```bash
pip install streamlit pandas plotly joblib requests scikit-learn
```

3. Run the application:

```bash
streamlit run app.py
```

Open `http://localhost:8501` in your browser.

## Note
Predictions are based on historical data and machine learning models. Actual match results may vary.
